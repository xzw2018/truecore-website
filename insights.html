a server.Size the system for your applications, then check memory, storage, rack space and expansion options.Read guide

01 · Start with the applications

List the applications, concurrent users, virtual machines and expected growth. Database, virtualization and file-server workloads use resources differently. Use software vendor guidance and measured workload data to size the system.

02 · Size memory and storage

Check memory type, capacity, available slots and channel population rules. For storage, assess capacity, read/write patterns, drive interfaces, controllers and data protection. Adding more drives does not always deliver a proportional performance gain.

03 · Check installation conditions

Verify rack height and depth, rail compatibility, power connectors and cooling. Check that server NICs, switches, transceivers and cables support the same link speeds and interfaces.

04 · Check expansion options

Record occupied slots, drive bays and power supply capacity. Identify what the system needs now and what you may add later. Confirm supported configurations in the manufacturer’s documentation for the exact model.

NETWORK / 02PORTS / UPLINK / MANAGEMENT02 / SWITCHES · FOUR KEY CHECKSHow to choose
a network switch.Compare access ports, uplink capacity, management features and PoE power against the devices on your network.Read guide

Count ports and check interfaces

List workstations, servers, access points and other connected devices. Record their port types and speeds, allow for planned additions, and count uplink ports separately from access ports.

Assess uplink traffic

Check where traffic goes: between local devices, to servers or through the gateway. Size uplinks for concurrent traffic and application demand; device count alone is not enough.

Choose management features

Decide whether you need VLANs, link aggregation, access control or monitoring. Check each model’s documentation for supported features, scale limits and operating conditions.

Calculate the PoE budget

Check the PoE standard and power draw of each powered device, then compare the total with the switch’s available budget. Verify power supply and cabling specifications. A PoE switch may not deliver maximum power on every port at once.

cable compatibility.Check both ends of the link: device support, port speed, optical specifications and cable type.Read guide

Identify both devices and ports

Record device models, software versions, port types and target speeds at both ends. Check the manufacturer’s supported transceiver and cable lists, including port modes and coding restrictions.

Match fiber, reach and wavelength

Use the fiber type specified for the transceiver: single-mode and multimode are not interchangeable. Rated reach depends on the specified fiber and link conditions. Match connectors, wavelengths and transmit/receive orientation. Single-fiber bidirectional modules need complementary wavelength pairs.

Compare optics, DACs and AOCs

Pluggable optics, direct-attach copper cables (DACs) and active optical cables (AOCs) differ in reach and device support. Confirm compatibility for the exact cable model and length, even for short links.

Label and document the link

Record both port numbers, transceiver part numbers, cable type, length and location. Keep these details with the network documentation to help diagnose cabling, compatibility and configuration faults.
